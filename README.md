# 🛒 Minha Lista de Supermercado

PWA simples, moderno e mobile-first para criar e organizar listas de compras de supermercado.

O aplicativo funciona diretamente no navegador e armazena os dados localmente no dispositivo utilizando **IndexedDB**, sem necessidade de conta, servidor ou sincronização em nuvem.

## ✨ Principais funcionalidades

* 📝 Múltiplas listas de compras
* 📦 Cadastro de produtos
* 🏷️ Marca, unidade e categoria
* ☑️ Controle de itens comprados e pendentes
* 💰 Valores e cálculo automático dos totais
* 📊 Resumo de cada lista
* 🔎 Pesquisa, filtros e ordenação
* 💵 Histórico de preços
* ⭐ Lista de desejos
* 🛒 Comprar novamente
* 📋 Copiar produtos entre listas
* 📋 Duplicação de listas configurável
* 📁 Arquivamento de listas
* 🗑️ Lixeira e restauração
* ↩️ Desfazer exclusões
* 💾 Exportação e importação de backups
* 📤 Compartilhamento de listas
* 🎨 Tema claro, escuro ou sistema
* 📱 Interface otimizada para smartphones
* 📴 Funcionamento offline como PWA

## 🔐 Privacidade

A versão atual mantém os dados localmente no dispositivo.

Não utiliza:

* Login
* Firebase
* Servidores próprios
* Sincronização em nuvem
* Analytics
* Coleta de preços
* APIs externas
* Envio automático dos dados das listas

O usuário pode exportar seus dados através do sistema de backup.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* IndexedDB
* Service Worker
* Web App Manifest
* PWA

Sem frameworks ou dependências externas para as funções principais.

## 🚀 Instalação

O projeto pode ser executado diretamente através do GitHub Pages ou instalado como PWA em dispositivos compatíveis.

Após a instalação, o aplicativo pode continuar funcionando offline.
